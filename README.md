Lantern Keeper （守灯人 · 拾光） is a small lighthouse arcade game in plain HTML, CSS and JavaScript. You are the keeper on the seawall at night: move to catch falling fireflies and charge the lighthouse to 100% before the dark tide takes your last flame. Shadow blocks cost a life; rare golden sunstones restore one. Combos multiply your score, and the tide grows faster and trickier across 8 levels. Play with arrow keys or A/D, the mouse, or touch; Space starts, P pauses, M mutes. No build step, no dependencies, works offline.

## Run it

```sh
python3 -m http.server 8000 --directory game
# then open http://localhost:8000 in a browser
```
